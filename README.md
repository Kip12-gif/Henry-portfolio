## 🚀 Overview
This repository hosts the master portfolio web application for **SpatialCraft Studio**, highlighting production-ready geospatial applications built with Python, Streamlit, Folium, and NetworkX.

## 📂 Featured Applications Included
1. **NomadSpots:** Global workspace & coffee scout with interactive Folium maps and AI recommendations.
2. **UrbanGreen:** Neighborhood tree canopy registry and carbon offset estimator.
3. **LAPSSET Corridor:** Network graph least-cost pipeline routing between Turkana and Lamu.
